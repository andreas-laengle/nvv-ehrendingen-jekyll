## Security Review

- Identified a conditional XSS risk: search results interpolate page titles and text into `innerHTML`. Exploitation requires the ability to modify indexed site content; no public content-submission path was found.
- `Gemfile.lock` is ignored, and Bundler Audit is not installed, limiting dependency reproducibility and automated vulnerability checks. No vulnerable gem was confirmed in the available environment.
- No backend, authentication, public forms, or API endpoints were found. Production response headers were outside the repository review.

## Verification

`bundle exec jekyll build` passed after the changes. Existing Sass deprecation warnings remain. The local Jekyll server was started at `http://localhost:4000`.
